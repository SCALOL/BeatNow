# Project Title

A rhythm-survival game where players control a central shield to deflect projectiles fired from all directions. The challenge lies in surviving until the end of the track while maintaining a high accuracy rate in sync with the music.

## Project Overview

A rhythm-based game developed for a "Music and Sound" course, focusing on audio-driven mechanics. 

Practice on polishing game audio system and planning workflow for music and sound production in game

---
## How to Play
Goal : Successfully defense rhythm bullet as many as possible until game music is over.

- Control defensing direction by mouse
- Failed defensing cause you no score.
- Each unique color bullet provide scores unequally.

## Built With
- Unity 6000.3.4f1

## Key Learning

- **Technical Audio Engineering:** Developed a MIDI-to-Level mapping system to synchronize dynamic gameplay elements directly with musical data.
- **Acoustic Optimization:** Mastered digital signal processing (DSP) techniques, including Reverb and Frequency Filtering, to ensure sonic clarity between SFX and BGM.
- **System Architecture:** Applied the Singleton Pattern to build a modular MIDI and UI Manager system, enhancing code scalability and maintainability.
- **Sound Production:** Gained end-to-end experience in Music Production using FL Studio, from original composition to technical MIDI integration.
